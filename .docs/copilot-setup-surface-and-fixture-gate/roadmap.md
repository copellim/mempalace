## Cross-phase Forward Dependency Check

- Phase 2 depends on the fixture gate completed in Phase 1. The raw capture prerequisite is already satisfied, so the remaining dependency is committed sanitized input data, not a reusable abstraction.
- Phase 3 depends on the normalizer and harness work from Phase 2, but it reuses the same `normalize.py` and `mine --mode convos` path rather than requiring a new extension point.
- Docs created in Phase 1 should be structured so later hook/backfill sections can be appended without renaming or moving the VS Code Copilot entry point, but no dedicated extension mechanism is needed.
